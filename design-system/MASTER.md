# Giaoly design system

Direction: light, calm, readable on desktop, mobile and projection screens.
Search basis: UI UX Pro Max `education quiz presentation dashboard` design-system; minimal dashboard direction.

- Background #f5f7fb, surface #ffffff, text #17243c, secondary text #52627a.
- Primary blue #315bcb, active tint #edf2ff, borders #dce3ef.
- Correct answer #16634b on #edf9f2, accompanied by a check mark or pair/step label.
- System sans-serif fonts supporting Vietnamese; presenter question 24–37 px, options 18–25 px, tabular countdown.
- 44 px minimum touch controls, visible keyboard outlines, semantic labels and native forms/dialogs.
- Layout mobile first; full-width admin library with seven category tabs and an on-demand native editor dialog, question choices at 640 px; content max width 1240 px.
- Reduced-motion media query removes transitions. No timed navigation or automatic answer reveal.
- Input content is text-escaped, never interpreted as user HTML.
